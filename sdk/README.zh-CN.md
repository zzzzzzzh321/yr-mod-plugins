# 插件侧 SDK

0.25 新增纯启动声明 `prism_support_defaults`，在第一次 Rules 读取前选择既有的棱镜支援倍率默认单位修复。参考组件直接返回 true，无需 INI 开关；未声明沿用宿主模式，显式 false 选择原版。存在 `[General]` 但缺少倍率键时，后续读取保留正确的百分比；数值解析、支援计数及发射仍归原所有者。实际组件的分层读取、保存恢复、延迟发射、旧模式和真实资源加载检查通过。配置17／状态1／API v1／WIT不变，但需要配套宿主；原生规则存档布局已变化，旧存档保留对应旧引擎和组件。本次不新增 PrismForwarding，未进行窗口或跨平台实跑。

0.24 新增独立的纯启动声明 `spawn_identity`，在正式资源接纳后批准 CnCNet `spawn.ini` 的国家编号及战役 Side 范围。参考组件直接声明扩展 Country 与 byte Side，不读取玩法配置或增加 INI 开关；未声明沿用宿主原模式，显式 false 可覆盖旧内置模式。输入先由唯一解析器读取一次，再于原 Ready 流程按固定组件策略批准；国家是否注册、地图、人数和颜色仍由现有所有者校验。战役 Side／CampaignID 仍是元数据，显式 Scenario 仍使用记录0。实际组件的人类／电脑国家、阵营和基地车、旧实现、资源重建及七种真实资源加载检查通过。社区测试覆盖帧解码和同一批准入口，未安装全局快照，也未实际启动窗口／联网；独立网络房间描述的国家范围仍由既有协议校验。配置版本仍为17、状态版本仍为1，API v1/WIT不变，仍需配套宿主。 接口见[启动声明](api/src/startup.rs)。

0.23 新增一次性 `type_sound_resource` 目录，接通 `Promote.VeteranSound`／`Promote.EliteSound`。插件沿实际 Techno 读取点保留继承全局、静音和已注册音效三态，宿主校验固定 SOUNDMD 来源及原生类型身份后一次绑定；军衔、位置音效和 EVA 仍由原机制维护。已注册的字面 `none` 是音效，静音仅关闭音效、不关闭 EVA。未声明保留旧模式，显式空目录在旧构建中也使用全局音效。不增加 INI 开关或逐次晋升 Wasm 调用。实际晋升到派发、存档后继续升级、来源变化拒绝、旧实现、共享 PCX GPU 及七种真实资源模式检查通过；未测试音频设备实际播放，仍需配套新版宿主。 详见[类型音效目录](api/src/audio.rs)。

0.22 新增一次性 `cameo_resource` 目录，迁移普通、晋升及超级武器的 PCX 图标。插件按实际 Rules／固定 ART 读取点保留文件名，宿主继续共用原文件名读取器、PCX/SHP 解码和图集；晋升 PCX 缺失时先回退普通 PCX，再走既有 SHP 路径，完全透明的 PCX 仍保持选中。安装即声明，不增加 INI 开关或逐图标 Wasm 调用。未声明保留旧模式，显式空目录选择原版。实际组件 GPU、同组件存档恢复、旧实现、七种真实资源模式及上一版组件加载检查通过。正式图标绑定在场景完成并经过共同 TypeReset 后发生，中间配置暂存不代表原生 Super 扩展跨 ClearScene 存活；整体迁移仍未完成。 该能力仍需配套新版宿主，见[接口](api/src/cameo.rs)。

0.21 新增可选 `match_rules.anim_damage`，为原有动画伤害选择所属方来源与 ART 弹头优先级；实际引用、计时、累积和接收仍由宿主统一维护。参考组件安装即启用，不添加 INI 开关；缺失声明保留原模式，显式 false 选择原版行为。实际动画、旧构建与针对性真实资源加载检查通过；不是 Weapon=／Damage.Delay= 扩展，仍需配套新版宿主。

0.20 新增可选的 `match_rules.building_presentation`，选择建筑 SHP／MAKE 独立调色板与 DestroyAnim 所属方颜色回退。安装参考组件即声明，不增加 INI 开关；原引擎继续维护 ART、PAL、动画和绘制，在构造前刷新同一资源目录。实际组件、保存恢复、GPU、旧实现与真实资源加载检查通过，不包含新的建筑动画或 voxel 调色板扩展。

0.19 新增可选纯声明 `long_list_readers`，在冷 Rules 读取前选择三个既有列表的容量；未声明保留原模式，显式128可覆盖旧内置模式。参考组件安装后直接使用2048，General 分组与物理行限制保持原行为，详见下方开发指南。

`api` 和 `wit` 是固定版本的开发依赖，来源与版本见 [source.json](source.json)。引擎仓库维护权威接口，本工程通过明确的 SDK 更新同步快照；日常编译不访问引擎目录。

`package` 是在本工程维护的组件打包工具，`dev-kit` 提供完整的[独立开发指南](dev-kit/README.zh-CN.md)。快速构建与工程职责见[根目录 README](../README.md)。

参考组件0.7.0保持API v1、WIT、配置版本5及状态版本1不变；四个已外置Ares模块只在新对局安装后默认启用，仍可通过`[VeraFeatures]`显式`no`关闭，Shield/Overload仍需显式开启。默认选择归插件所有，不是SDK或宿主对所有组件施加的默认。旧组件和冻结配置保留原行为，读档仍要求当前作品提供相同摘要的原组件。最低宿主要求及高槽武器边界见[独立开发指南](dev-kit/README.zh-CN.md)。

当前 0.25.0 开发候选使用配置版本17、状态版本1，新增独立的固定EVA、Country前读、Country-only配置及阵营静态声明能力。共享配置与玩法增量已验收，国家菜单、旗帜、加载画面与音乐已接入并通过相关行为及旧实现检查，此前阵营增量的七种真实资源模式及上一版组件加载已通过；0.18 接入侧栏、EVA SetSide、消息颜色、胜负文字及结算；需要配套新版宿主。0.7.0保留交付继续留存，详见[开发指南](dev-kit/README.zh-CN.md#阵营共享配置与玩法)。
